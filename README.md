# ama-mobstack

> HAMAL VENTURE STUDIO · Public · Apache-2.0

Reusable execution patterns for AI agent teams: gates, handoffs and receipts, plus integration examples for the [Hanzo](https://github.com/hanzoai) ecosystem.

## Status

**Early scaffold.** This repository does not yet contain runnable code.

The MobStack execution standard is maintained at [`MajorDream444/Mobstack`](https://github.com/MajorDream444/Mobstack). This repository will hold contribution-ready patterns and examples built on that standard. It will not maintain a second, competing version of it.

## What will live here

- Execution patterns: gates, handoffs, receipts
- Integration examples with Hanzo MCP and tools
- Tutorials and contribution-ready components that may be proposed upstream to Hanzo

## What will never live here

- Private agent definitions, founder workflows or approvals
- Mentor interviews, unpublished mentor knowledge or personal data
- Secrets, keys or credentials
